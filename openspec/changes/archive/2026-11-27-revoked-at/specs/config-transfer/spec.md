# Spec Delta

## ADDED Requirements

### Requirement: Поле revokedAt в файле
Разрешение в файле конфигурации MAY содержать необязательное поле `revokedAt` (строка `ГГГГ-ММ-ДДTчч:мм`), дополняющее поля `startsAt` и `expiresAt`. Экспорт MUST писать его у отозванных разрешений, `version` остаётся 3. Если поле задано, оно MUST быть реальным моментом, строго позже `startsAt` и строго раньше `expiresAt` (когда они заданы). Файл без поля, в том числе прежних форматов, принимается: разрешение считается неотозванным.

#### Scenario: Круговой обмен с отзывом
- **WHEN** экспортирована конфигурация с отозванным разрешением и файл загружен обратно
- **THEN** получается равная конфигурация, `revokedAt` сохранён

#### Scenario: Прежний файл без revokedAt
- **WHEN** загружен файл прежнего формата без `revokedAt` и без временных разрешений
- **THEN** `import-status` сообщает «Конфигурация заменена», доступ считается так же, как раньше, кнопок отзыва нет

#### Scenario: Неверный момент отзыва
- **WHEN** у разрешения `revokedAt` равно `2026-02-30T10:00` или не строка
- **THEN** файл отвергнут, причина указывает место `permissions[N].revokedAt`

#### Scenario: Отзыв вне интервала
- **WHEN** `revokedAt` не позже `startsAt` или не раньше `expiresAt`
- **THEN** файл отвергнут, причина указывает разрешение `permissions[N]`, конфигурация и сохранённая копия остаются прежними
