# Proposal

## Why

Сейчас файл применяется сразу после выбора: администратор видит результат только когда конфигурация уже заменена, и вчерашняя загрузка показала, чем это кончается. Нужно сначала показать, какие разрешения появятся, какие исчезнут и какие изменятся, и отдельно назвать отзывы, которые импорт сохранит. Применять файл должно отдельное нажатие, а отмена не должна ничего менять.

## What Changes

- После выбора корректного файла экран показывает предпросмотр `import-preview` с кнопками `import-confirm` и `import-cancel`. Конфигурация, расчёт доступа, экспорт и `localStorage` не меняются, пока предпросмотр открыт.
- Различия разрешений называются строками трёх видов: `import-preview-added-<id>`, `import-preview-removed-<id>`, `import-preview-changed-<id>`. Строка `import-preview-kept-<id>` называет отзыв, который подтверждение сохранит. Если различий нет, показан `import-preview-empty`.
- Предпросмотр показывает ровно то, что сохранит подтверждение: сравнение идёт с конфигурацией после переноса отзывов, а не с «сырым» файлом.
- Подтверждение применяет файл и показывает `import-status`, отмена закрывает предпросмотр без следов. Файл с ошибкой по-прежнему даёт `import-error` и закрывает предпросмотр.
- Различия пользователей, групп и сервисов показываются одной сводкой `import-entities` (по числам), чтобы пустой предпросмотр не вводил в заблуждение.
- Правило отзывов не меняется и закреплено сквозным тестом: отзыв после экспорта остаётся в силе после подтверждения.
- Идентификаторы `data-testid` прошлых шагов не переименованы.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `config-transfer`: импорт идёт в два шага (предпросмотр, подтверждение).

## Impact

- `src/app/import-preview.ts` (новая чистая функция `buildImportPreview`), `src/app/index.ts` (`startImport`, `importPreview`, `confirmImport`, `cancelImport` вместо `importJson`), `src/components/ConfigTransfer.tsx`, `src/components/App.tsx`, `src/components/permission-text.ts`.
- Тесты: `import-preview.test.ts`, `ImportPreview.test.tsx`; прежние тесты импорта дополнены нажатием `import-confirm`. Затрагиваются СБ 2 (до подтверждения данные не меняются) и СБ 3 (меняются только разрешения, названные в предпросмотре).
- Вне изменения: пошаговый выбор строк для применения, отмена уже применённого импорта.
