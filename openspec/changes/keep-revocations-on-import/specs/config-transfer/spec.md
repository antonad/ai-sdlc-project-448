# Spec Delta

## ADDED Requirements

### Requirement: Импорт сохраняет отзывы
При успешном импорте отзыв, сделанный в текущей конфигурации, MUST сохраниться: если в файле есть разрешение с тем же `id`, субъектом, сервисом, `startsAt` и `expiresAt`, у которого нет `revokedAt` или он позже, оно MUST получить `revokedAt` из текущей конфигурации. Остальные разрешения SHALL браться из файла без изменений. Без отзыва в текущей конфигурации файл применяется как есть. Файл с ошибками MUST отвергаться целиком, как прежде.

#### Scenario: Файл, выгруженный до отзыва
- **WHEN** временное разрешение подрядчика выгружено, затем отозвано кнопкой `permission-revoke-<id>`, затем загружен тот же файл через `import-input`
- **THEN** `import-status` сообщает «Конфигурация заменена», разрешение остаётся отозванным, `access-result` на момент после отзыва внутри интервала отвечает «Доступа нет», `access-sources` не показывается, без действий человека

#### Scenario: Тот же файл без отзыва
- **WHEN** тот же файл загружен, а в текущей конфигурации разрешение не отозвано
- **THEN** `access-result` внутри интервала отвечает «Доступ есть»

#### Scenario: Другая выдача под тем же id
- **WHEN** в файле разрешение с тем же `id`, но другим сервисом, субъектом или интервалом
- **THEN** отзыв не переносится, разрешение берётся из файла как есть

#### Scenario: Два отзыва
- **WHEN** в файле у разрешения свой `revokedAt`, а в текущей конфигурации другой
- **THEN** действует более ранний момент

#### Scenario: Файл с ошибкой
- **WHEN** загружен файл с ошибкой, а в текущей конфигурации есть отзыв
- **THEN** файл отвергнут целиком, конфигурация и сохранённая копия прежние, отзыв на месте
