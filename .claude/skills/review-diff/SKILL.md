name: review-diff
description: Ревью текущего диффа по docs/architecture.md и docs/security-requirements.md. Использовать перед коммитом или PR.
---

1. Получи дифф (`git diff` и `git diff --staged`).
2. Прочитай `docs/architecture.md` и `docs/security-requirements.md`.
3. Проверь дифф по пунктам:
   - расчёт доступа только в `src/domain/access.ts`, без чтения часов;
   - компоненты не импортируют `src/domain` и не обращаются к `localStorage`;
   - нет сетевых вызовов;
   - импорт проверяется целиком, при ошибке данные и `localStorage` не меняются;
   - выдача и удаление затрагивают только выбранное разрешение;
   - удаление одного разрешения не ломает независимые источники доступа;
   - на новое поведение есть тест.
4. Выведи список нарушений: файл:строка, какое правило нарушено, как исправить. Если нарушений нет, так и напиши.

Ничего не правь сам, только сообщай.
