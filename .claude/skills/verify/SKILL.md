---
name: verify
description: Полный прогон проверок проекта перед завершением задачи или коммитом. Использовать, когда изменение готово и нужно убедиться, что оно проходит CI.
---

Запусти по порядку и остановись на первой ошибке, исправь причину и начни с неё заново:

1. `npm run typecheck`
2. `npm test`
3. `npm run lint` (при ошибках формата: `npm run lint:fix`)
4. `npm run lint:arch`
5. `npm run build`

В отчёте перечисли, что прошло, что упало и что исправлено. Не заявляй «готово», пока все пять шагов не зелёные.
