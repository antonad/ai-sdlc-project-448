# Ревью изменения temporary-permissions

База: текущее рабочее дерево. Git-диффа под рукой нет, поэтому ревьюится код в `src` и тесты по задачам из `tasks.md` архивного изменения `openspec/changes/archive/2026-11-27-temporary-permissions/`. Изменение уже архивировано и позже расширялось тремя другими: `datetime-permissions` (дни стали минутами), `revoked-at` (отзыв как `revokedAt`) и `utc-instants` (моменты в UTC, версия формата 4). Поэтому поля `startsOn`/`endsOn`, поле «На дату» и `dateToDay` из проекта заменены современными эквивалентами (`startsAt`/`expiresAt`, `evaluation-time`, `momentToDate`); они сверяются по намерению проекта, а не по буквам. Сверка идёт с актуальными спеками `openspec/specs/`, `docs/architecture.md`, `docs/security-requirements.md` и `docs/adr/0001-time-model.md`.
